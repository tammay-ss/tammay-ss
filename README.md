# hey, i'm tanmay.

*somewhere between breaking things and figuring out why they broke.*

I'm a CS (Data Science) student at VIT Chennai, interested in the strange intersection of human problems and technical solutions.

I build things with code, teach machines to recognise patterns, and occasionally spend more time understanding why something failed than celebrating when it works. From medical imaging and synthetic data generation to full-stack applications and AI-assisted systems, I'm interested in what happens when an idea leaves the whiteboard and meets reality.

I don't think every problem needs a complicated solution. I do think most interesting problems deserve a second look.

### things i work with

- **Languages:** Python, Java, C++, JavaScript, TypeScript, SQL
- **Development:** React, Node.js, FastAPI, Firebase, REST APIs
- **AI / ML:** PyTorch, YOLO, NLP, predictive modelling, synthetic data generation
- **Data:** NumPy, Pandas, exploratory data analysis, statistical modelling
- **Tools:** Git, Jupyter Notebook, Label Studio

### things i've tried to figure out

- Teaching machines to find anatomical landmarks in medical images.
- Generating synthetic battery data without losing touch with physical reality.
- Building applications that make complicated workflows a little less complicated.
- Turning unstructured emergency information into something useful for decision-making.
- Understanding why models fail, why systems break, and what the evidence actually tells us.

### how i like to build

Experiment. Find the cracks. Trace them back to their source. Try again.

I'm interested in software engineering, applied AI/ML, data science, and the space where these fields overlap. I like working on problems that don't arrive with a neat solution and learning technologies by putting them to use.

### currently

Still learning. Still building. Still asking why.

*The code is an attempt at an answer. There's usually another question underneath it.*
